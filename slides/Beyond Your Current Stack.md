# Beyond Your Current Stack

> A map of the software ecosystem — and how to learn it without learning everything.

ဒီ presentation ရဲ့ ရည်ရွယ်ချက်က technology အသစ်တွေကို အကုန်လိုက်သင်ဖို့ မဟုတ်ပါဘူး။ Developer တစ်ယောက်အနေနဲ့ ကိုယ်နေ့တိုင်းသုံးနေတဲ့ stack ရဲ့ အပြင်မှာ ဘာတွေရှိသေးလဲဆိုတာကို **map တစ်ခုလို မြင်နိုင်ဖို့** ဖြစ်ပါတယ်။

ကိုယ်မသိတဲ့ technology တစ်ခုတွေ့တဲ့အခါ “ဒါကိုလည်း အခုချက်ချင်းသင်ရမယ်” လို့ မယူဆဘဲ — ဘာ problem ကို ဖြေရှင်းဖို့ ပေါ်လာတာလဲ၊ ဘယ်အခြေအနေမှာ အသုံးဝင်လဲ၊ မလိုအပ်ရင် ဘာကြောင့်မသုံးသင့်လဲဆိုတာ သိထားနိုင်ဖို့ပါ။

## ဒီ slide က ပြောချင်တာ

Software ecosystem က အရမ်းကျယ်ပါတယ်။ ဒါပေမယ့် ecosystem တစ်ခုလုံးကို ကျွမ်းကျင်ဖို့ မလိုပါဘူး။ ကိုယ့်လက်ရှိ stack က ecosystem တစ်ခုလုံးမဟုတ်ဘူးဆိုတာ သိထားပြီး **အပြင်မှာ ဘာတွေရှိလဲ သိခြင်း** က ပထမအဆင့်ပါ။

ဒီ presentation တစ်ခုလုံးကို `Explore → Build → Learn → Repeat` ဆိုတဲ့ loop တစ်ခုလိုလည်း ကြည့်နိုင်ပါတယ်။

## နောက်ထပ်စဉ်းစားစရာ

Developer တစ်ယောက်ရဲ့ skill ကို “သိတဲ့ framework အရေအတွက်” နဲ့ပဲ တိုင်းတာမယ်ဆိုရင် ecosystem ကြီးလာလေလေ နောက်ကျကျန်ခဲ့သလို ခံစားရနိုင်ပါတယ်။ ဒီ talk က အဲဒီ mindset ကို ပြောင်းပြီး **အရာတွေကို map လုပ်နိုင်ခြင်း၊ problem နဲ့ tool ကို ချိတ်ဆက်နိုင်ခြင်း၊ မသိတာကို စုံစမ်းနိုင်ခြင်း** ကို အရေးကြီးတယ်လို့ ပြောထားတာပါ။
