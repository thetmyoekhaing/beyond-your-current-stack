# Build Something You Don't Normally Build

## Explore → Build → Learn → Repeat

ဒီ slide က presentation တစ်ခုလုံးရဲ့ learning loop ကို ပြန်ပိတ်ပေးထားပါတယ်။

**Explore** — ကိုယ်မသိတဲ့ ecosystem တစ်ခုကို စူးစမ်းပါ။

**Build** — သိချင်တဲ့အရာကို project သေးသေးလေးနဲ့ လက်တွေ့စမ်းပါ။

**Learn** — Build လုပ်ရင်း မသိတာတွေကို လိုအပ်သလို ပြန်လေ့လာပါ။

**Repeat** — တစ်ခါပြီးတာနဲ့ ရပ်မနေဘဲ နောက်ထပ် problem နဲ့ ပြန်စပါ။

## Hackathon ကို laboratory လို သုံးပါ

Hackathon ရဲ့ goal ကို “project တစ်ခုအောင်မြင်အောင် build ရမယ်” လို့ပဲ မထားပါနဲ့။ ကိုယ့်အတွက် **technology အသစ်၊ workflow အသစ်၊ problem အသစ်တွေကို စမ်းသပ်တဲ့ laboratory** တစ်ခုလို သုံးနိုင်ပါတယ်။

Project က မအောင်မြင်လည်း learning ရနိုင်ပါတယ်။ တစ်ခါတလေ အဲဒီ learning က project အောင်မြင်တာထက် ပိုတန်ဖိုးရှိနိုင်ပါတယ်။

## Presentation ပြီးတဲ့အခါ ယူသွားစရာ မေးခွန်း ၃ ခု

### What will you read this week?
ဒီအပတ်မှာ ဘယ် repo, docs, PR, source file တစ်ခုကို ဖတ်မလဲ?

### What will you build?
ကိုယ်ပုံမှန်မလုပ်ဖြစ်တဲ့ အရာထဲက ဘာကို သေးသေးလေး စမ်းမလဲ?

### What will you finish?
စမယ့်အရာတွေအများကြီးထက် တကယ်ပြီးအောင်လုပ်မယ့် အရာတစ်ခုက ဘာလဲ?

> **Go build.**

အဓိကက technology အားလုံးကို သိလာဖို့မဟုတ်ပါဘူး။ **ကိုယ့်လက်ရှိ stack ရဲ့အပြင်ကို သွားကြည့်ဖို့ မကြောက်တော့တာ** ဖြစ်ပါတယ်။
