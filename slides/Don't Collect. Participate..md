# Don't Collect. Participate.

Learning လုပ်တဲ့အခါ **collecting** လုပ်နေတာနဲ့ **participating** လုပ်နေတာကို ခွဲကြည့်ဖို့လိုပါတယ်။

## Collecting — Passive
- Browser tab 43 ခု ဖွင့်ထားတာ
- စထားပြီး မပြီးသေးတဲ့ course တစ်ခု
- Bookmark လုပ်ထားပြီး မဖတ်ဖြစ်တဲ့ article
- တစ်ဝက်တစ်ပျက်ကြည့်ထားတဲ့ tutorials
- Mute လုပ်ထားတဲ့ Discord server

ဒီအရာတွေ အများကြီးရှိနေပေမယ့် ကိုယ့်ရဲ့ ability က တကယ်တိုးလာတယ်လို့ မဆိုနိုင်ပါဘူး။

## Participating — Active
- Repo တစ်ခုကို clone လုပ်ပြီး run ကြည့်ပါ
- README ထဲက typo တစ်ခု ပြင်ကြည့်ပါ
- ကိုယ့်ရဲ့ first issue ကို ဖွင့်ကြည့်ပါ
- အသုံးမဝင်သေးတဲ့ project တစ်ခုတောင် ship လုပ်ကြည့်ပါ
- Public မှာ question တစ်ခုမေးကြည့်ပါ

ဒီ actions တွေက result သေးသေးလေးဖြစ်ရင်တောင် **တကယ်လုပ်ဖူးတဲ့ experience** ကို ပေးပါတယ်။

## အဓိက takeaway

> One thing you actually tried is worth more than a hundred things you bookmarked.

ဒါကြောင့် slide ရဲ့ challenge က ရိုးရိုးလေးပါ — **ဒီ weekend မှာ ညာဘက်က action တစ်ခုတည်းကို ရွေးပြီး လုပ်ကြည့်ပါ။**
