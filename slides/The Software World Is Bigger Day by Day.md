# The Software World Is Bigger Day by Day

> “There is a lot more out there than what I currently use.”

နေ့တိုင်းကိုယ်သုံးနေတဲ့ technology တွေက software world တစ်ခုလုံးမဟုတ်ပါဘူး။ ဒီ slide မှာ ecosystem ကို အပိုင်းခြောက်ပိုင်းခွဲပြီး ကြည့်ထားပါတယ်။

### Frontend / Interface
React, Vue, Svelte လို web technologies တွေ၊ Swift/Kotlin/Flutter လို application UI technologies တွေရှိပါတယ်။ CSS ကိုလည်း UI အလှဆင်တာလောက်မဟုတ်ဘဲ ကိုယ်ပိုင် language တစ်ခုအနေနဲ့ သိထားဖို့လိုပါတယ်။

### Systems / Backend
Go, Rust, Elixir, Java လို languages တွေရှိသလို REST, gRPC, GraphQL လို systems တွေပြောဆိုဖို့ နည်းလမ်းတွေရှိပါတယ်။ Auth, sessions, OAuth လို concepts တွေက application တွေရဲ့ နောက်ကွယ်မှာ အမြဲတွေ့ရတတ်ပါတယ်။

### Data / Intelligence
Postgres, SQLite, DuckDB လို databases တွေကနေ Pandas, PyTorch လို tools တွေအထိ ရှိပါတယ်။ Embeddings နဲ့ vector search လို concept တွေကလည်း data/AI ecosystem ရဲ့ အစိတ်အပိုင်းတွေပါ။

### Platform
Docker, Kubernetes, AWS, GCP, Terraform, CI/CD, observability စတာတွေက application ကို run, deploy, scale, monitor လုပ်တဲ့ဘက်မှာ ပါလာပါတယ်။

### Foundation
Linux, networking, TLS, Git, code review, testing, profiling စတာတွေက framework တစ်ခုထက် ပိုအခြေခံကျတဲ့ knowledge တွေပါ။

### Workflow
Editor, terminal, GitHub, feature flags, rollouts, documentation စတာတွေက developer တစ်ယောက်ရဲ့ နေ့စဉ်လုပ်ငန်းစဉ်ထဲက အစိတ်အပိုင်းတွေပါ။

## အဓိက takeaway

**You don't need to know all of this. You need to know it exists.**

“သိတယ်” ဆိုတာ tutorial အကုန်ဖတ်ပြီးသွားတာ မဟုတ်ပါဘူး။ “ဒီလို problem ရှိရင် ဒီလို tool category တစ်ခု ရှိနိုင်တယ်” လို့ ချိတ်ဆက်စဉ်းစားနိုင်တာကို ဆိုလိုပါတယ်။
